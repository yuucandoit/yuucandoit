## About Me: Who I Am & What I Do

I am a **Software Engineer & Quality Assurance Engineer** based in Jakarta, Indonesia, with a formal background in Informatics Engineering (B.Sc., Universitas Indraprasta PGRI).

My engineering discipline sits at the intersection of application development and software quality:

### 1. As a Software Engineer
- **Back-End Architecture**: Building and maintaining enterprise back-end systems primarily with PHP (Laravel), as well as developing RESTful microservices with Go and Python (FastAPI).
- **Front-End & Mobile**: Crafting cross-platform hybrid mobile applications and web interfaces using Angular, Ionic Framework, Vue.js, and modern utility CSS (Tailwind CSS).
- **Database Architecture**: Designing relational schemas, enforcing transactional integrity, and optimizing query performance in PostgreSQL and MySQL.
- **Server Deployment & DevOps**: Managing Linux server environments, orchestrating containerized services with Docker, and configuring Nginx reverse proxy routing for autonomous production deployments.

### 2. As a Quality Assurance Engineer
- **Automated API Testing**: Constructing comprehensive API testing collections, parameter validations, and environment staging workflows in Postman.
- **Mobile Hardware Testing**: Inspecting and debugging hybrid Android applications on real hardware via Android Debug Bridge (ADB) and scrcpy screen mirroring.
- **System Stability & Audits**: Conducting pre-release staging audits, performance bottleneck assessments, and database consistency validations to ensure reliable production releases.

Instead of treating software development and testing as disconnected silos, I bridge the gap: building clean code with testing in mind, and verifying systems with a developer-level understanding of the underlying architecture.
